# 创意启航

折纸爱心、纸飞机飞行与个人创意卡片的交互原型。

在线体验：https://chloew0324.github.io/creative-flight-h5/

仓库根目录可直接发布到 GitHub Pages，使用 main 分支、/(root)，无需构建。

本地预览：在此目录执行 `python3 -m http.server 8787`。

投票记录仅保存在浏览器本地；红包、订阅及分享为演示交互。

设计与交互遵循用户选定的2024录屏，后续修改前请先阅读 [录屏设计规范](录屏设计规范.md) 与 [项目约束](AGENTS.md)。

回归检查：`node check-recording.cjs`。手机按实际可用视口和安全区等比适配。
